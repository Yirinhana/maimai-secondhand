# 部署候选配置

本目录是部署前的候选配置；尚未连接腾讯云、配置DNS/TLS或公开上线。用户新提供的服务器、Hermes占用、备案与证书报告已收录到[服务器准备清单](../docs/development/server-readiness.md)，其中机器状态尚未独立核验。

目标是Ubuntu24.04上的Nginx、Java21单应用和MySQL，前端及JAR在本地构建；2GB机器不承担Node/Maven构建。初始Java堆512MB、Hikari5连接，MySQL建议128至256MB buffer pool，须通过实际负载再调整。Hermes若与网站共机，需重新分配内存，不能将以上数字当容量验收。

候选布局：`/opt/maimai/releases/<版本>/` 保存每个交付包，`/opt/maimai/current` 指向当前版本；`/var/lib/maimai/`保存图片，`/etc/maimai/maimai.env`保存凭据。新版本健康检查与真实流程通过前保留旧包，至少保留最近两个；数据库迁移采用增量，不自动回滚或删除数据。

头像通过 `MAIMAI_AVATAR_DIR=/var/lib/maimai/avatars` 独立持久保存。公开头像也由后端核验当前数据库引用后返回，不给 Nginx 增加该目录的静态映射。替换后的旧图片本轮保留且旧链接失效；上线前需确定上传存储预算、告警与经确认的旧文件保留/清理策略。备份须同时覆盖数据库、商品图片、头像、私信图片和售后证据，避免只备份 JAR。

启用前步骤：确认SSH与服务器现状；创建专用非root运行用户及最小数据库权限；配置独立邮件账号、有效地图应用和物流服务；安装JDK/MySQL/Nginx并关闭数据库公网访问；填好环境文件和TLS路径；先执行`nginx -t`检查候选配置，再经用户确认切换服务。示例文件不包含自动覆盖服务器配置的命令。

文件权限也属于首次部署前置检查：systemd 示例中的 `maimai` 用户须能读取候选 JAR，并拥有 `/var/lib/maimai/` 下各图片子目录的写入权限；Nginx 用户仅需读取前端静态文件及公开商品图片，不应读取私信和售后证据目录。凭据文件 `/etc/maimai/maimai.env` 应由 root 管理并设为 `0600`，由 systemd 读取注入服务；不要给 Web 服务读取权限。`/opt/maimai/current` 必须指向已完整传输和校验的版本目录，切换前核对 JAR、前端、VERSION 和校验清单齐全。实际账号名、目录所有权、链接切换和数据库权限需在获准部署时根据服务器现状执行，本说明没有在服务器创建这些内容。

数据库备份应使用专用备份账号及受限client配置，`mysqldump --single-transaction --routines --events`输出加密后存到服务器外；图片同时备份。须在隔离数据库做恢复演练并保存实际记录。备份保留周期、远端存储和加密凭据尚未配置，因此目前不声称有可恢复备份。

微信真实付款、退款和平台分账仍受主体资质与接口开发约束；生产环境拒绝模拟付款和开发邮件入口。当前候选包即使能够启动，也不能据此宣布真实交易可上线。

TLS样例以证书已经存在为前提。首次签发和续期方式需明确选择DNS-01，或为HTTP-01单独提供challenge文件路径；不能把SPA回退页当challenge响应。HTTPS响应头策略需结合高德资源域、子域HTTPS现状和嵌入需求实测，再确定CSP、HSTS等值。MySQL实际systemd单元、启动就绪、服务重启恢复和停机连接排空也须在目标服务器检查，不能仅凭After顺序声明可用。
